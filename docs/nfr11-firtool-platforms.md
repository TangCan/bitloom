# NFR11 — multi-platform firtool assets

`firtool_asset_for_host()` maps:

| Host | Asset |
|------|-------|
| linux-x64 | `firrtl-bin-linux-x64.tar.gz` |
| linux-arm64 | `firrtl-bin-linux-arm64.tar.gz` |
| macos-x64 / arm64 | `firrtl-bin-macos-*.tar.gz` |
| windows-x64 | `firrtl-bin-windows-x64.tar.gz` |

Unsupported triples require `RHDL_FIRTOOL_PATH`.
