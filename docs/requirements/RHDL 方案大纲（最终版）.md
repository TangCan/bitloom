# RHDL 方案大纲（最终版）

## 1. 项目概述

*   名称与定位：基于 Rust 的嵌入式 RTL 硬件描述语言
    
*   核心思想：硬件描述即合法 Rust 代码，通过过程宏生成 HIR
    
*   特色亮点：所有权模型防多驱动、显式时钟域、与 Chisel 互转、多视图建模
    

## 2. 设计目标

*   强类型安全
    
*   所有权模型适配硬件
    
*   组合/时序逻辑显式分离
    
*   参数化与代码生成
    
*   与 Rust 生态无缝集成
    
*   可综合子集明确
    
*   互转为一级设计目标（FIRRTL）
    
*   支持高层次综合（HLS）
    
*   提供丰富硬件 IP 库
    
*   内置可视化工具
    
*   **支持多视图建模，降低功能模拟器与周期精确模拟器生成难度**
    

## 3. 核心设计原则

*   嵌入式 DSL
    
*   显式优于隐式
    
*   编译期检查前置
    
*   中间表示标准化（HIR 与 FIRRTL 对齐）
    
*   可逆子集定义
    
*   分层抽象（RTL / HLS / IP）
    
*   **多视图建模原则**：允许模块同时提供功能视图与周期精确视图
