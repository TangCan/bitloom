# 4. 整体架构与工作流

RHDL 的整体架构围绕 **Rust 编译器 + 过程宏 + 硬件中间表示（HIR）** 构建。硬件设计以合法的 Rust 代码编写，通过过程宏展开为 HIR，然后由多个后端生成目标产物。整个工具链深度集成在 Cargo 生态中，支持代码生成、仿真、可视化以及与 Chisel 的互转。此外，**多视图建模**机制使得同一设计源可以同时生成功能模拟器与周期精确模拟器。

## 4.1 系统架构总览


## 4.2 核心数据流

RHDL 编译流程的核心是 **Rust 源码 → HIR → 目标产物** 的数据转换链条。功能模型则走另一条路径：**Rust 源码 → 普通 Rust 编译 → 功能模拟器**。

```mermaid
flowchart LR
    A[Rust 源码<br>（.rs 文件）] -->|rustc + 过程宏| B[展开后的 Rust 代码<br>（构造 HIR 的代码）]
    B -->|执行| C[HIR 数据结构]
    A -->|普通 Rust 编译| G[功能模拟器代码]
    C -->|序列化/遍历| D[后端处理]
    D --> E[Verilog 文件]
    D --> F[FIRRTL 文件]
    D --> H[周期精确模拟器]
    D --> I[可视化输出]
    D --> J[形式验证模型]
    G --> K[功能模拟器库/可执行]

```

HIR 是核心中间表示，包含以下信息：

```mermaid
classDiagram
    class HIR {
        +modules: Vec~Module~
        +top_module: String
    }
    class Module {
        +name: String
        +ports: Vec~Port~
        +instances: Vec~Instance~
        +wires: Vec~Wire~
        +registers: Vec~Reg~
        +combinational_blocks: Vec~CombBlock~
        +sequential_blocks: Vec~SeqBlock~
        +metadata: Metadata
    }
    class Port {
        +name: String
        +direction: Direction
        +type_info: TypeInfo
        +width: usize
    }
    class Reg {
        +name: String
        +width: usize
        +clock_domain: ClockDomain
        +init_value: Option~Value~
    }
    class Metadata {
        +original_type_names: Map
        +parameter_values: Map
        +source_locations: Map
        +functional_model_info: Option~FunctionalInfo~
    }
    HIR "1" *-- "many" Module
    Module "1" *-- "many" Port
    Module "1" *-- "many" Reg

```

## 4.3 编译与生成流程

### 4.3.1 编译阶段

RHDL 的编译完全嵌入 Rust 的构建过程。当运行 `cargo build` 或 `cargo test` 时，过程宏在编译期间执行，构建 HIR 并执行检查。

```mermaid
sequenceDiagram
    participant User as 开发者
    participant Cargo as Cargo
    participant rustc as Rust 编译器
    participant Macro as RHDL 过程宏
    participant HIR as HIR 构建器
    participant Check as 硬件检查器

    User->>Cargo: cargo build / test
    Cargo->>rustc: 编译项目
    rustc->>Macro: 遇到 #[module] 等宏
    Macro->>HIR: 解析模块结构，构建 HIR
    HIR->>Check: 执行编译期检查
    Check-->>Macro: 检查通过 / 报错
    Macro-->>rustc: 生成可执行代码（仿真用）
    rustc-->>Cargo: 构建产物
    Cargo-->>User: 成功 / 错误信息

```

### 4.3.2 硬件生成流程

通过 `cargo rhdl generate` 子命令触发硬件生成，生成 Verilog 或 FIRRTL。

```mermaid
flowchart TD
    A[cargo rhdl generate<br>--top MyModule<br>--format verilog] --> B{查找 HIR}
    B -->|从编译产物缓存| C[加载 HIR]
    B -->|重新构建| D[cargo build<br>生成 HIR]
    D --> C
    C --> E[Verilog 后端]
    E --> F[生成 Verilog 文件<br>my_module.v]
    C --> G[FIRRTL 后端]
    G --> H[生成 FIRRTL 文件<br>my_module.fir]

```

## 4.4 仿真与测试工作流

RHDL 的仿真器允许在 Rust 测试中直接实例化模块并操作信号，完全复用 `cargo test` 基础设施。功能模拟器则作为普通 Rust 库使用。

```mermaid
flowchart TB
    subgraph 测试代码
        T1[创建模块实例]
        T2[设置输入信号]
        T3[tick 时钟]
        T4[读取输出]
        T5[断言]
    end
    subgraph RHDL 周期精确仿真器
        S1[组合逻辑求解]
        S2[时序逻辑更新]
        S3[波形记录]
    end
    subgraph RHDL 功能模拟器
        F1[调用功能方法]
        F2[内部状态更新]
        F3[返回结果]
    end
    T1 --> T2 --> T3 --> T4 --> T5
    T3 --> S1
    S1 --> S2
    S2 --> S3
    T4 --> S3
    T5 -->|通过/失败| 结果

    T1 --> F1 --> F2 --> F3

```

示例测试代码结构：

```rust
#[test]
fn test_counter() {
    let mut sim = Simulator::new(Counter::new());
    sim.set_input(enable, true);
    sim.tick();
    assert_eq!(sim.get_output(count), 1);
    sim.tick();
    assert_eq!(sim.get_output(count), 2);
}

```

仿真器还支持波形导出，生成 VCD/FST 文件供外部工具查看。

```mermaid
sequenceDiagram
    participant Test as Rust 测试
    participant Sim as RHDL 仿真器
    participant Wave as 波形记录器
    Test->>Sim: tick()
    Sim->>Sim: 计算组合逻辑
    Sim->>Sim: 更新寄存器
    Sim->>Wave: 记录信号变化
    Sim-->>Test: 返回
    Test->>Wave: 导出 VCD/FST
    Wave-->>Test: 波形文件

```

## 4.5 与 Chisel 互转架构

RHDL 以 FIRRTL 为交换格式，实现与 Chisel 的双向转换。架构上需要两个转换器：

*   **FIRRTL → Chisel 生成器**：将 FIRRTL 转为 Chisel 源码（低层次）
    
*   **FIRRTL → RHDL 导入器**：将 FIRRTL 转为 HIR，再生成 RHDL 源码
    

```mermaid
flowchart LR
    subgraph RHDL 侧
        RHDL_SRC[RHDL 源码]
        HIR[HIR]
        RHDL_GEN[RHDL 源码生成器]
    end
    subgraph 中间格式
        FIRRTL[FIRRTL]
    end
    subgraph Chisel 侧
        CHISEL_SRC[Chisel 源码]
        CHISEL_COMP[Chisel 编译器]
        CHISEL_GEN[Chisel 代码生成器]
    end

    RHDL_SRC -->|过程宏| HIR
    HIR -->|FIRRTL 后端| FIRRTL
    FIRRTL -->|FIRRTL→Chisel 生成器| CHISEL_SRC
    CHISEL_SRC -->|Chisel 编译| FIRRTL
    FIRRTL -->|FIRRTL→RHDL 导入器| HIR
    HIR -->|RHDL 源码生成器| RHDL_SRC

```

转换过程中的元数据保留：

```mermaid
flowchart TB
    subgraph RHDL 编译
        A[RHDL 源码] -->|提取元数据| B[HIR + 元数据]
        B -->|FIRRTL 后端| C[FIRRTL + 注释]
    end
    subgraph Chisel 生成
        C -->|解析注释| D[FIRRTL→Chisel 生成器]
        D --> E[Chisel 源码<br>保留原始名称/参数]
    end
    subgraph 反向导入
        F[Chisel 生成的 FIRRTL] --> G[FIRRTL→RHDL 导入器]
        G --> H[HIR]
        H --> I[RHDL 源码]
    end

```

## 4.6 扩展功能集成架构

### 4.6.1 HLS 集成

HLS 前端作为独立模块，接收算法级 Rust 函数，输出 HIR，与 RTL 描述无缝混合。

```mermaid
flowchart TB
    subgraph 设计输入
        A["RTL 模块<br>#[module]"]
        B["算法函数<br>#[hls]"]
    end
    A --> C[HIR]
    B --> D[HLS 前端]
    D -->|调度/分配/绑定| C
    C --> E[Verilog / FIRRTL]

```

### 4.6.2 IP 库集成

IP 库以普通 Rust crates 形式发布，通过 Cargo 依赖引入，直接被用户模块例化。

```mermaid
flowchart LR
    User[用户项目 Cargo.toml] -->|依赖| IP1[rhdl-uart crate]
    User -->|依赖| IP2[rhdl-fifo crate]
    User -->|依赖| IP3[rhdl-axi crate]
    IP1 -->|定义模块| UartTx
    IP2 -->|定义模块| Fifo
    IP3 -->|定义模块| AxiStream
    User -->|例化| UartTx
    User -->|例化| Fifo

```

### 4.6.3 可视化集成

可视化工具从 HIR 和仿真波形中提取信息，生成图形描述。


## 4.7 多视图模拟器生成架构

多视图建模允许同一模块同时提供功能视图和周期精确视图。工具链根据 feature 或命令生成对应的模拟器。

### 4.7.1 多视图模拟器生成流程

```mermaid
flowchart TB
    subgraph 模块源码
        A[UartTx 模块]
        A --> B["功能视图方法<br>#[functional_model]"]
        A --> C["周期精确视图<br>#[sequential] / #[combinational]"]
    end

    subgraph 编译路径
        B -->|普通 Rust 编译| D[功能模拟器代码]
        C -->|过程宏| E[HIR]
        E -->|仿真器后端| F[周期精确模拟器代码]
    end

    subgraph 产物
        D --> G[功能模拟器<br>Rust 库 / C 共享库]
        F --> H[周期精确模拟器<br>Rust 库 / C 共享库 / 波形]
    end

    subgraph 一致性验证
        G --> I[随机测试比对]
        H --> I
        I --> J[形式化等价验证]
    end

```

### 4.7.2 桥接适配器

功能视图与周期精确视图之间可以通过桥接适配器进行交互，使软件可以驱动硬件模型。

```mermaid
flowchart LR
    SW[软件调用] -->|方法调用| TLM["事务级接口<br>send_byte()"]
    TLM -->|桥接适配器| RTL[信号级接口<br>tx_data / tx_start / tx_busy]
    RTL -->|逐周期 tick| HW[周期精确模拟器]

```

---

RHDL 的整体架构以 Rust 工具链为基石，通过 HIR 统一中间表示，实现了从设计、验证到生成、互操作的完整闭环。多视图建模的引入使得架构能够同时支持功能模拟与周期精确模拟，覆盖从软件开发到硬件验证的全流程。其灵活性允许开发者根据需要选择抽象层次，并与其他硬件生态无缝协作。
