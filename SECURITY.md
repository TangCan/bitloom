# Security Policy

## Supported versions

Bitloom toolchain crates are currently **0.x**. Security fixes are applied on the latest published `0.x` line when feasible.

## Reporting a vulnerability

Please open a **private** security advisory on the repository if available, or email the maintainer listed in `Cargo.toml` / git history.

Do **not** file public issues for undisclosed vulnerabilities.

This project is unrelated to [samitbasu/rhdl](https://github.com/samitbasu/rhdl).
