设计是生成器，不是 rustc 里抽出的网表

cargo rhdl build 跑用户的 Rust、得到冻结电路图、再降后端。过程宏只是 builder 的语法糖。

  • 本页是走读。可执行规则在 ARCHITECTURE-SPINE.md 的 AD-1…AD-26。

4 / 11

电路只有一张图

  • FrozenHir 是 FIRRTL 6 可逆子集的层次 AST（模块、实例、Connect、寄存器）。展平只许发生在后端私有视图。
  • 未冻结图出不了 rhdl-hir。elaborate 和 import 都返回 Result<FrozenHir, Diagnostics>。freeze 是私有末步。
  • builder 是对着这张图的会话，不是第二张可变网表。宏展开到 builder。
  • HIR 的出生只有两处：用户的 Elaboratable::elaborate()，以及 FIRRTL 导入。两边走同一 freeze。

5 / 11

阶段一：写出来的电路长什么样

  • 每个模块一个显式 Clock、一个同步高有效 Reset。tick 就是这个时钟的一个上升沿。Verilog 是 always @(posedge clock)。emit 不得发明端口。
  • #[combinational] / #[sequential] 必须写。不完整组合赋值是错，没有隐式 latch。
  • 端口是 Input<T> / Output<T>。表面算术严格同位宽；要变宽就写 pad/trunc。FIRRTL 的 n+1 只能从这些节点来。
  • 周期精确路径没有堆、线程、默认浮点。#[functional_state] 进不了 HIR。
  • freeze 拒绝多驱动、宽/向不匹配、未驱动输入（除非标明悬空）。所有权可以引导 API，不是证明。

6 / 11

两套仿真；互转是文本不是 Scala

  • 周期精确：从 FrozenHir tick，同一套 API dump VCD。
  • 功能视图：手写 #[functional_model]，普通 Rust。禁止从 HIR 生成 TLM。
  • 对照只比 PortValues（按端口名和运行时宽度）。Bits<W> 是门面，降到运行时宽度。
  • 与 Chisel 的契约是 FrozenHir ↔ FIRRTL version 6.0.0 文本。不维护 Scala，不指望 Chisel 读 .fir。
  • 导入先把 last-connect 收成唯一驱动。往返要保住层次、端口、实例图、运算和寄存器；注释可以丢。
  • 阶段一 rhdl-firrtl 可以有解析/AST，不能写用户面向的 .fir，也不能调 firtool。

阶段二已经定下的不变式

  • 表面加厚（AD-20）： if/match、同位宽运算、pad/trunc、同步 Reg 复位语义；Bundle/Vec 仍禁止静默可用。
  • Mem（AD-21）： 表面用 CHIRRTL 友好名（Mem/SyncReadMem）；降级/互转锚规范 mem；跨时钟存储只能经命名 CDC FIFO。
  • 多时钟（AD-22）： Clash 式 phantom 域（可改 ASSUMPTION）；非法跨域 freeze 失败；默认模块仍是 AD-15 单时钟。
  • 复位/使能（AD-23）、FST（AD-24）、HLS 外挂（AD-25）、合同海拔（AD-26）。

对应阶段二 PRD：FR22 → FR26 → FR23…；交付顺序不要颠倒。

9 / 11

现在不要做的事

这些不是「没写所以自由发挥」。做了就是第二个工具链。

  • 产品已有 FR、脊柱未钉实现形状：bridge/形式等价/C ABI/覆盖率、IP/LSP、Analog、CLI 其余动词。
  • 不要做：从 HIR 生成 TLM；自研 HLS 调度；用所有权当多驱动证明；Chisel Scala 当互转契约；未配对就钉 firtool-1.156.0；发布 rhdl/rhdl-bits。
  • 不要做：在 AD-22 未修订前另起一套 CDC 检查并与 phantom 并存。
