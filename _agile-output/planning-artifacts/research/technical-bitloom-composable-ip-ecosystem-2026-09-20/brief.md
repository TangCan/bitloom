# Bitloom 可组合 IP 生态调研简报

用户已于本轮确认研究计划。决策：下一阶段怎样扩充内置 IP、组合能力与第三方接入，以有限维护资源交付可用系统。

- 类型 technical；形状 explore；标准档 standard，3名并行研究助手；每方向每轮最多8个实际读取来源，最多2轮；normal关键结论独立核查；red_team off；无工作流编排服务，使用原生助手。
- 搜索面：web 搜索/打开官方文档及上游仓库；无额外研究搜索连接器。
- 方向一：IP优先级与生态实践；方向二：协议组合/CSR/验证；方向三：第三方分发与维护。
- 范围：原生基础IP与外设、单时钟AXI4-Lite外设系统、外部RTL适配。复杂DDR/PCIe/Ethernet只评估接入策略，不许虚构可移植性或成熟度。
- 交付：research.md 精炼结论与来源；implementation-plan.md 详细阶段/故事/接口/验收/估算；imports/project-audit.md 本轮项目事实审计；digests与memlog保存过程。
- 项目上下文仅用于提出问题。外部研究不把仓库文档当作行业证据；实施计划的本地状态须独立审计并明确本地来源。
- 预计15–25分钟；不修改产品代码、不发布、不push，不分配新的正式FR/Epic编号。
- 研究与计划获授权；新产品实现及修改架构约束尚未获本轮授权。
