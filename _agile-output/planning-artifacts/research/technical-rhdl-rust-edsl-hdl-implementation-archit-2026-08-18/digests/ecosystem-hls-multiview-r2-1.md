**Q2 synthesis (sourced only):** “Functionally identical” on the XLS homepage is about **software-speed design vs generated hardware**, with functions **and** procs listed as supported. Dual-execution **simulation** of procs/channels is documented (`eval_proc_main`, fuzzer includes Verilog). **Z3 LEC** is documented as **IR function → Z3** and **IR vs post-synth netlist**. No retrieved page states that Z3 LEC proves proc/channel equivalence.

**Q4 synthesis (sourced only):** essent is pinned to Scala FIRRTL **1.6.1** with an explicit **no-bump** statement. Spec **6.0.0** is a 2026-05-12 language release. No retrieved source claims essent parses/emits FIRRTL **version 6.0.0**. Usable as a FIRRTL sim backend for **SFC 1.6.x / Chisel-pre-CIRCT FIR** with single-clock constraints; **not** documented as a spec-6.0.0 backend.
