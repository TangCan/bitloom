## Intent

**Problem:** FR47 要求 CLI/API **生成** Rust 功能模拟器工件；目前仅有手写 abstraction，21.2 还显式禁止生成入口。

**Approach:** 在工具链（`bitloom-sim` + `cargo bitloom`）从 `FrozenHir` 生成可 `cargo test` 的 Rust 功能模拟器 crate；黄金夹具对已知向量给出预期 `PortValues`。不交付 SystemC。

## Boundaries & Constraints

**Always:** 生成器属工具链；设计 crate 仍只依赖 `bitloom-prelude`；对照用 `PortValues`；品牌 Bitloom。

**Ask First:** 无。

**Never:** SystemC/TLM-2.0；周期精确工件/桥接（21.4）；FR30 生成路径联验（21.5）；完美 HLS 级 codegen。

## I/O & Edge-Case Matrix

| Scenario | Input / State | Expected Output / Behavior | Error Handling |
|----------|--------------|---------------------------|----------------|
| 生成成功 | FrozenHir（counter 级） | 写出含 `Cargo.toml`+`src/lib.rs` 的功能模拟器 crate | IO 错误上抛 |
| 黄金向量 | reset + 3 周期 | `data_out == 3`（PortValues） | 断言失败 |
| 无 SystemC | 产物/文档 | 无 SystemC 合同 | N/A |
