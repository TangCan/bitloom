## Acceptance Criteria

1. **前置与组合。Given** 128.1风险门、128.3 IRQ、126.4参数FIFO已done，**When** 新建缓冲UART，**Then** 设计只依赖bitloom-prelude，复用CsrBlock和两实例ParamSyncFifo<8,4>，同一ElaborateSession定义与最终一次finish/freeze；新独立类型、静态寄存器描述、共享定义与Elaboratable入口共用实现。支持同定义复用、重命名定义、实例隔离和既有freeze前诊断，不拼FrozenHir、不建第二HIR。公开名字/签名/端口和描述字段先由ATDD冻结，本文建议不是已有API。
2. **六CSR与唯一副作用。Given** addr16/data32/WSTRB4、local 00 CTRL RW(bit0 enable)、04 BAUD_DIV RW32、08 STATUS RO(bits0 rx_nonempty/1 tx_full/2 tx_busy/3 rx_busy)、0c TX_DATA WO低8、10 RX_DATA RO低8、14 EVENT W1C低4，**When** 请求提交，**Then** 仅非reset上升沿req_valid&&req_ready提交一次；成功有效TX写push、成功RX读pop，各只有一次。提交沿形成响应快照，下一周期valid，背压稳定且不再提交，消费沿无refill。全部CSR reset0、未列位读0写忽略；RO写（含零WSTRB）/WO读/洞/未对齐/高地址别名SLVERR，失败读与写响应rdata0，无软件副作用。合法零有效mask写OKAY无副作用，TX未选byte0即使满也OKAY。静态描述同源输出确定性C头/Markdown，黄金地址独立；原文prelude-only示例及C11消费者实际编译。
3. **配置与全宽分频。Given** 固定8N1、LSB first、TX idle高、每bit P=BAUD_DIV+1个ACLK，**When** 合法配置和启动竞争，**Then** BAUD_DIV保留全部32位，启用须DIV>=3；关闭且空闲可存0..2，使能状态下不得改无效DIV。busy=TX或RX任一活动；忙时任何有效BAUD写SLVERR，忙时改变enable的有效CTRL写SLVERR，CTRL不改变enable不因此拒绝；检查WSTRB合并候选值，零有效mask不报busy错误。关闭不启动新帧、允许预填TX/读已有RX且不清FIFO。空闲成功配置在该沿形成有效配置：新TX帧/RX下降检测采用它并锁存分频，disable同沿不得启动；拒绝/零mask不改变配置。DIV=ffffffff对应2^32周期，不能32位加一溢出或截8位；代表分频真实逐拍，全宽极值另列近终点/算术/形式证据，不冒称长周期全跑。
4. **RX同步与精确采样。Given** RX双同步级和历史随reset清0，**When** 接收，**Then** 用沿前第二级同步值与历史检测下降沿，记该FSM采样沿为e；H=floor(P/2)，start在e+H确认，data[k]在e+H+(k+1)P，stop在e+H+9P，全部消费同一第二级同步流。奇数P取较早中心。start确认不低取消且无RX/framing；stop低丢帧并framing。reset释放idle-high只有0→1，不伪造下降；释放时持续低也不伪造帧，必须先见高再下降。DIV3、4、5，原始针脚相位0.1/0.5/0.9 ACLK，00/ff/55/a6及短start/低stop独立向量核对拍号、FIFO及事件；至少两帧仅一个stop、无额外idle，在DIV3与DIV4各相位全部依序接收。真实loopback之外必须独立串行发送与TX解码，发送器不等待DUT busy/ready。
5. **FIFO与四原始事件。Given** TX/RX各8×4寄存器FIFO、无空直通，**When** CSR和串行引擎同沿动作，**Then** TX满时即使同沿取队首仍拒有效写，RX空时即使同沿到达仍空读SLVERR；RX满时即使成功软件pop也丢新帧、保留原队列余项并overflow，不能借同沿空位接纳。普通非空非满支持push/pop。合法RX成功push产生EVENT bit0，TX实际取队首进入发送器产生bit1（不是busy结束），RX满丢帧bit2、低stop丢帧bit3；本地W1C `(old & ~clear)|new_event`，set胜clear，事件独立总线背压。实际UART→Irq夹具接IRQ1=RX、2=TX腾位、3=overflow|framing；IRQ0/4不受影响，无第6IRQ。IRQ接沿前原始脉冲非sticky；本地EVENT不清而清IRQ不重触发，下一事件仍有效，覆盖本地/IRQ同沿clear与新事件。
6. **兼容、reset和物理边界。Given** 旧UartTx/UartRx及其VIP/手写FL已交付，**When** 新增wrapper，**Then** 保留旧8-bit baud端口（含DIV0实验）、旧采样/发送延迟与独立入口并回归。wrapper/CSR/双FIFO/组合IRQ同域同步高有效reset，reset胜提交与事件，清配置/FIFO/串行状态/同步链/历史/待响应；取消账本区分已取队首、正在发送和已回响应，已发到物理线的bit不能回滚。系统aresetn由外部控制器同步断言和释放再转换，反相不是同步器。逻辑两级同步与DIV3测试不证明板级可靠性、亚稳态MTBF或波特率失配容限；无parity/流控/分数分频/异步FIFO/BRAM/外部核扩大。
7. **实证、API与M3闭合。Given** 独立scoreboard及适用有限形式性质，**When** 七步全部完成，**Then** direct/FIRRTL/Chisel分别实际执行UART及组合RTL，formal prove/cover与原始综合分别记录，代表DUT行为故障负控制必须被指定断言检出；适用单模块native两引擎/generated分列，含实例入口明确unsupported，不为测试扩层级产品。新增公开符号逐项登记FR142/minor，CI接普通/后端/形式/软件例与失败工件，实际cargo clean→cargo fmt --all→just test全workspace通过。只有128.1–128.5全部done且证据齐才同本故事关闭Epic128/M3/FR197，写关闭映射并更新当前状态；不代交付129完整系统/核心矩阵、130外部试点或整个Phase24，FR189 deferred/NFR91保持，不push/publish、不改工具钉或版本。

### 可行实现方向（API交ATDD冻结）

建议新增`ip/uart_csr.rs`及独立如`UartCsr`类型，提供`registers()->CsrBlock`、`define_module(&mut ElaborateSession, impl Into<String>)->Result<String,Diagnostics>`和共用定义体Elaboratable。保持标准12个CSR端口拼写，另RX/TX及四原始事件的总线或独立输出形式由ATDD选定并固定，不额外公开内部debug状态。旧uart.rs直接finish且baud8、RX无同步/半bit/错误接口，不原地扩大旧类型。

|寄存器|mask|建议owner/候选拒绝|
|---|---|---|
|CTRL 00|00000001|Leaf RW；busy且candidate.enable不同，或candidate.enable=1而当前DIV<3拒绝|
|BAUD_DIV 04|ffffffff|Leaf RW；busy或当前enable且candidate<3拒绝|
|STATUS 08|0000000f|External RO；来自沿前FIFOflags及串行busy，reset时动态值0|
|TX_DATA 0c|000000ff|None WO；提交前full动态reject；CSR零有效mask自动旁路reject并不commit|
|RX_DATA 10|000000ff|External RO；提交前empty动态reject，成功read_commit直接pop|
|EVENT 14|0000000f|Leaf W1C；四自然事件一次合并，硬件set优先|

单请求不能同沿写CTRL和BAUD。方向必须无环：`current + wdata/WSTRB → candidate/mask → old_busy/old_config拒绝 → successful commit → effective_config → idle start/latch → next state`；不得拿新busy反喂reject，也不能让candidate依赖commit。忙判断用沿前TX/RX状态，包括最后忙沿；成功空闲配置后启动的新帧锁存新DIV。TX/RX可同时活动，各自活动分频明确锁存。

FIFO复用现有`ParamSyncFifo<8,4>::define_module`：两个实例共享一个定义，flush绑0、共同reset。input_ready=!full/output_valid=!empty来自注册占用，满拒push即使pop、空无bypass，正好匹配合同；无需另存同一队列payload或重写FIFO。TX input_valid只由TX_DATA成功write_commit，RX output_ready只由RX_DATA成功read_commit；自然引擎按提交前flags动作，不用响应消费驱动push/pop。原始事件沿前组合送本地和IRQ同沿捕获，不能多寄存一拍。

全宽安全实现可选择32位倒计时装DIV得到P周期；H可用`(DIV>>1)+(DIV&1)`避免DIV+1在32位溢出，e时装H-1则e+H确认，后续装DIV每P采样。这是推导建议，必须独立向量证实，不要求特定内部名字或让测试复制DUT helper。DIV=ffffffff的H=80000000；若用33位P须验证所有后端宽度。
