## Dev Notes

### Required Reuse And Boundaries

- 主系统来源为 `crates/bitloom/tests/fr198_peripheral_system.rs` 及其 AXI/direct testbench。重构可以提取公共生成/runner，但不得降低 Story129.2 现有事务、断言、随机 seed、VCD 和 Yosys `check -assert` 门槛。
- 组合必须遵循 AD-30：同一 `ElaborateSession` 注册真实模块，顶层一次 `finish/freeze`，不拼接 `FrozenHir`，不创建第二套 IR。设计 crate 仍只依赖 `bitloom-prelude`。
- 共同内部 reset 为同步高有效；公开无状态边界仅执行 `core_reset = ~aresetn`。`aresetn` 由外部控制器同步断言/释放的前提必须保留；逻辑反相不是同步器。
- 固定窗口和 IRQ 位序不得变化：UART `0x0000`、GPIO `0x0100`、Timer `0x0200`、IRQ `0x0300`；IRQ bit0–4 为 Timer match、UART RX、UART TX dequeue、UART overflow|framing、GPIO rising edge。
- native Interpreter/Compiled 和 GeneratedFunctional 层级继续明确 unsupported。不得为了矩阵增加未授权的原生层级产品路径。

### Verification Design

- 三后端必须测试同一个完整 AXI 四外设系统；direct CSR 图作为第二组合继续单独执行。若为控制时间只在 direct 图做部分三后端复核，必须有冻结合同明确允许；当前合同没有该豁免。
- 独立黄金模型手写地址和副作用，不能调用 DUT 的 CSR 描述、译码或 next-state。UART 预期不能读取内部 busy/state。
- formal 是有限证明：明确 assumptions、深度和覆盖边界。负控制应修改 harness/property 或受控 DUT 副本，不得污染产品代码。
- CI 中普通 `cargo test --workspace` 会保留专用 ignored 外部门禁；新增 job 必须显式执行它们，且日志中 `ignored` 不算 PASS。
- 证据至少包含 machine-readable index、原始日志、生成源/RTL、filelist、VCD、工具版本和 SHA256。clean 前先归档。
