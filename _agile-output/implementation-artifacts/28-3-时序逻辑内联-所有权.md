## Intent

**Problem:** Designers cannot safely reuse synthesizable transforms inside `#[sequential]` without risking multi-drive / illegal mutable signal borrows; FR75 Cap-R-56/70 requires elaborate-time inline plus Cap-R-70 ownership diagnostics.

**Approach:** Mirror 28.2 on `ElaborateSession`: `inline_seq_fn(dst_reg, args, synth_violations, ownership_violations, span, |args| SeqInline::…)` (+ marker helper). Cap-R-60 then Cap-R-70 (tokens + auto-detect second `Reg.d` in the same sequential process → `rhdl::E0146`); legal closures expand once into ordinary sequential `Reg.d` assigns. Reuse `CombInline` via `SeqInline::Comb`. FrozenHir never stores `Fn` (NFR36). Cross-process multi-drive remains AD-4 `rhdl::E0140`.

## Boundaries & Constraints

**Always:** FR75 seq path (Cap-R-56); Cap-R-70 ownership (`E0146`); call/respect SynthesizableClosure check (28.1); NFR36 no closure residue; AD-4 freeze multi-drive after expand; Bitloom / `bitloom-prelude` design surface.

**Never:** store Fn / closure IR in FrozenHir / backends; silent skip of Cap-R-60/70 violations; new HIR closure nodes; rely on within-process dedup to hide second `Reg.d`.

## I/O & Edge-Case Matrix

| Scenario | Expected |
|----------|----------|
| `inline_seq_fn` Inc / Mux + empty violations | ordinary Reg.d AssignExpr; tick matches handwritten golden |
| Cap-R-60 synth violations | E0143–E0145; no expand; finish fails |
| Second Reg.d / ownership token (Cap-R-70) | `rhdl::E0146`; no expand |
| Two sequential processes drive same Reg.d | `rhdl::E0140` (AD-4) after expand |
| Freeze after legal inline | no Closure / Fn residue (NFR36) |
| Design crate deps | only `bitloom-prelude` |
