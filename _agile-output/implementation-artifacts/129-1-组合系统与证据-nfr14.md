4. **独立验收与两种复用。Given** 系统交付须实际运行，**When** 固定129.2/129.3责任矩阵，**Then** 完整AXI系统由独立主端配置Timer、控制GPIO32、真实UART串行收发并清IRQ；另一不同拓扑组合用于检验复用，不能仅改模块名。主端黄金手写关键地址/副作用，AW/W独立、读写并发、各通道背压、全部WSTRB、访问错误及reset取消账本；UART用独立线端驱动/解码，不只软件模型自检。本地EVENT未清而清IRQ不重触发，后续新事件仍到达；reset清bridge/decoder/leaf/FIFO/FSM，已发送物理bit不承诺回滚。安全性不依赖ready公平，完成上界另列假设。至少两个不同组合实际行为验证，不拿旧127.4 peer或128.5局部UART→IRQ替代完整FR198。

### 架构与现有接口

AD-1/6/7/18/28/30：唯一FrozenHir、同session共用定义、一次finish、设计prelude-only；适用单模块native结果不能替代层级RTL。AD-31的外部源锁属于Epic130，本风险故事不下载或绑定外部IP。准确路径为`crates/bitloom-prelude/src/ip/axi_lite_csr.rs`、`csr_decoder.rs`、`uart_csr.rs`、`gpio/csr.rs`、`timer.rs`、`irq.rs`；后端目录仍`crates/rhdl-firrtl`，不要按包名猜路径。实际类型/签名和reset连接以现有源码为准，不使用研究中的timer_config或旧UartTx共享定义伪API。

共同CSR提交为非reset上升沿req_valid&&req_ready。提交沿形成快照，次周期valid，stall稳定，消费沿无refill。桥捕获AW/W/AR不等于CSR提交；全CSR最多一请求执行中，B/R各自保持槽。reset后读/完整写同时可选先读，再轮转；不完整写或无空响应槽的方向不能堵另一方向。WSTRB不改变地址错误优先级，失败读rdata0；AXI写核BRESP，CSR写响应rdata沿用各leaf合同，不向桥/decoder施加额外约束。系统必须核实输出及守恒/取消，不只内部窥探。

第二种拓扑建议直接CSR→同四窗/四真实外设（无AXI桥），与完整AXI版共用定义helper和事件接线；本风险门须最终固定这两种拓扑，129.2 ATDD再冻结具体私有helper/文件接口；不要求新增公开稳定类型。初始系统随机预算采用研究建议16个固定seed×1000个完成事务，另有每类必达定向计数；若按实测成本调整须保存覆盖与测时理由，不能静默减少或声称概率保证。两图均须实际RTL行为；可将定义helper放prelude-only example crate而非prelude核心，减少不必要API。不能只同图改名算第二组合。

复用已锁BFM：cocotb2.0.1、cocotbext-axi0.1.28、cocotb-bus0.3.0、find-libpython0.5.1、scapy2.7.0；Python3.12是已有环境要求。高层BFM可能对齐/拆分，非法地址/特殊WSTRB/reset仅AW等用原始通道且不能两个驱动同针脚。reset返回None为取消，不是OKAY。固定脚本`phase24_axi_bfm_probe.py`为工具接口探针，不是系统证明。

复位最小探针先检验既有typed路径：唯一Reset输入aresetn，组合UInt1再Eq形成Reset wire core_reset（不得叫rst），连接真实child状态。Chisel现有emit_instance_connects跳过child clk/rst、隐式Module继承reset是待实测风险，不能仅编译或让TB偷偷绑定额外reset掩盖。备选为源码随例子交付的最薄无状态RTL边界，明确系统产物=生成core+aresetn适配；三后端共用相同边界并实际跑、综合、源码绑定，不称全top由HIR生成或外部IP试点。风险门须以真实探针和AD-30确认一种合法路线，未解不得ready，不无记录修改后端或缩为仅高有效rst顶层。

工具Rust1.97.1/edition2024、firtool1.159.0、Chisel7.15.0；SBY身份依`scripts/ci-sby-pins.env`核完整tag/commit/安装模块和隔离Python路径。/tmp工具候选仅本机环境，不能写死到产品或复现命令。按需读取既有runner，保留exact测试执行数/非零场景/源起止当前SHA、日志与VCD，不用历史PASS并集。normal/-O下缺证据拒绝是过去经验；风险门不必复制整个UART验证框架。
