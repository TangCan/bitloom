## Intent

**Problem:** Path B / FR102 要求多视图属性**全矩阵**（`#[abstraction]` / `#[functional_model]` / `#[functional_state]` 及 `#[bridge]` / `#[both]`，或文档等价）作为可验收完成面。既有 FR29 手写 bridge/abstraction/both 与 FR78/FR92 adapter **模板**是配套，**不得单独关闭 FR102**（NFR14）。缺口：`#[functional_state]`（或文档等价）尚未作为可验收表面落地；缺少列出合法/非法组合门禁的合同文档；缺少正/负向 ATDD 证明 `functional_state` 等不泄漏进 HIR/`freeze`。

**Approach:** （1）新增 `docs/fr102-multiview-attribute-matrix.md`：钉死 NFR14 属性宏全矩阵（五行 + adapter 配套非充分）、合法组合、非法组合门禁；声明本页为 FR102 完成面。（2）在 `bitloom-macro` / `bitloom-prelude` 交付 `functional_state` 字段表面（`#[rhdl::module]` 识别并剥离；HostView 扩展剥离惰性属性），保证标注字段**不**进入端口表 / FrozenHir。（3）正/负向 ATDD：矩阵文档守卫；各属性可展开；含 `functional_state` 的模块 elaborate 后端口名不含软字段；非法组合文档+守卫；明确 FR78/FR92 模板 alone ≠ FR102。（4）sprint：`45-3` → done；**保持** `45-4` backlog；`epic-45` 仍 in-progress。**不**实现 FR103；**不**勾选 Epic 45 关闭。

## Boundaries & Constraints

**Always:** 实现风险记录属性/表面矩阵（含 `functional_state`）；正/负向 ATDD；文档列完整矩阵与非法组合门禁；`functional_state` 等不得泄漏进 HIR/`freeze`（继承 AD-5 / AD-18；45.1 未另开泄漏合同）；设计 crate 只依赖 `bitloom-prelude`；品牌 Bitloom；one-story-one-commit；完成面超出仅 adapter 模板。

**Ask First:** 若要把 `functional_state` 允许进入 FrozenHir（违反 NFR14 / AD-5）；若要用仅 FR78/FR92 模板勾选 FR102。

**Never:** 仅用 adapter 模板关闭 FR102；实现 FR103 IP 双模型或勾选 Epic 45 关闭（→45.4）；把 SystemC TLM（Epic 46）并入本故事；允许 `functional_state` 泄漏进 HIR/`freeze`；未文档化属性静默 no-op 却宣称矩阵完成。

## Dev Notes

### Decision — field attribute consumed by `#[module]`

Rust stable 无独立 field-proc-macro。`#[functional_state]` / `#[rhdl::functional_state]` 为 **`#[rhdl::module]`（及 HostView 属性宏）识别的惰性字段属性**：elaborate 端口循环**跳过**带该属性的字段；展开输出剥离该属性以免 rustc unknown-attr。文档等价可并列说明；**不得**把字段写入 FrozenHir 端口表。
