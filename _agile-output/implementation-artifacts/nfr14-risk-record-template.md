# NFR14 风险记录模板（Phase 7 / P3 门禁）

> **权威：** PRD `prd-rhdl-2026-08-19` **NFR14**；架构脊柱 **AD-28**（Phase 7 风险门禁）。  
> **用途：** 在将 FR46 / FR47 / FR48 / FR49（及适用的 **FR50**）对应 epic 或 story 标为 `ready` **之前**，复制本模板填写一份风险记录并放入 `_agile-output/implementation-artifacts/`（或挂在对应故事文件旁）。

---

## 使用说明（短）

1. **复制本文件**为 `nfr14-risk-<epic-or-fr>.md`（例：`nfr14-risk-epic-20-chisel.md`），或在故事旁路文件中保留同等字段。
2. **填满下方必填字段 (a)–(d)**；缺任一字段 = 记录无效。
3. **门禁：** 缺有效记录 ⇒ **不得**将 FR46 / FR47 / FR48 / FR49（及适用的 FR50）对应 epic/story 标为 `ready`，亦不得开工实现故事。见 AD-28 / PRD NFR14。
4. 若 **并行多项 P3** 工作（例：Epic 20–24 同时推进），除各 FR 记录外，须另写或在本记录中显式增加 **维护叠加 / Chipyard 式风险** 说明（人力、语义最低公分母、回归面膨胀）。
5. 本故事（19.1）只提供模板；**不**代替 Epic 20–24 的具体风险记录（20.1 / 21.1 / …）。
