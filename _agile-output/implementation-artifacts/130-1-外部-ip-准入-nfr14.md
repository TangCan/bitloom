## Dev Notes

### Architecture And Product Guardrails

- AD-31 要求在现有外部模块表示上绑定来源和锁定元数据；解析/获取在 CLI/构建层，设计依赖仍只允许 `bitloom-prelude`。不得把第三方源码嵌入 HIR、创建第二套 IR、让 prelude 在构建时联网，或顺带扩大 FR142。
- 当前 `crates/bitloom-prelude/src/ip/blackbox.rs::ExtBlackBox` 只有 `clk/rst/data_in/data_out` 端口，`vendor_blackbox_v()` 是无行为 stub。它可作为“外部文件参与编译”的机制探针，但不能升级外部支持矩阵。
- 130.2 负责 FR199 的来源清单、锁和离线重放；130.3 依赖 130.2 与 126.2，负责一个真实外部小核及外部支持行。130.1 不下载、vendoring、绑定或选择最终候选，不实现 manifest 产品 API。
- 首选候选只是 PULP common_cells stable v1.40.0 FIFO 方向。研究指出 master `cc_fifo` 与 stable `fifo_v3` 可能有路径/端口变化；实施时以 stable tag 的实际内容为准。Taxi 只作重新准入的备选，不可无记录切换。
- Bitloom 品牌和包边界保持；不改 Rust 1.97.1、firtool 1.159.0、Chisel 7.15.0、包版本或发布状态。FR189 仍要求已发布 `firtool > 1.159.0`，本 Epic 不处理该阻塞。

### Verification And Stop Conditions

- 工具发现只证明环境入口存在；网络 fetch 只证明当时可达；空壳编译只证明文件绑定机制。三者都不是 FR199 锁定/离线成功或 FR200 行为通过。
- 风险故事可使用本地临时目录探测，但所有可复核结论须归档到 `_agile-output/test-artifacts/130-1-*`，含命令、环境、源起止 hash、原始日志和退出码。不得把 `/tmp` 路径写成产品合同。
- 停止条件：无长期 owner；stable tag/commit 或递归闭包无法固定；许可证/NOTICE 或再分发责任不清；禁网重放失败；现有表示无法准确绑定必需参数/端口/reset；真实 RTL 与独立 oracle 分歧；需要新增未批准公共 API、工具 pin 或复杂外部核范围。
- 失败时保留原始失败和候选状态，130.2 保持 backlog。禁止默默换源、复制 master 内容冒充 stable、裁掉依赖、仅收录目录冒充适配、空黑盒输出零、把 compile-only 提升为 behavior-tested，或用核心 FR201 关闭吞并外部行。
- 维护叠加包括上游升级、递归依赖/许可证漂移、wrapper 端口和工具兼容、离线缓存、required CI 时间。先记录成本，不承诺未经测量的采用率、节省、PPA 或升级频率。
