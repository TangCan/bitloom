## Intent

**Problem:** Story 9.2 的 HLS 钩子默认「未启用 → unsupported」，不满足 FR35/AD-25 产品路径。

**Approach:** 钉死 Bambu 2024.10；`cargo bitloom hls` 始终为产品路径：发射 C → 调外挂 → 要求 .v/.sv；缺后端失败可读；`--emit-only` 仅供检查 C。

## Boundaries & Constraints

**Always:** 无树内 scheduling；缺后端非 silent 成功；文档默认可复现；`--help`；品牌 Bitloom。

**Ask First:** 无。

**Never:** 自研调度器；永久 unsupported 话术；实现 CI job（24.3）。

## I/O & Edge-Case Matrix

| Scenario | Input | Expected | Error |
|----------|-------|----------|-------|
| 产品路径 + bambu | `hls --function add` | ok=*.v | 后端非零 → error |
| 缺 bambu | 无 PATH/BAMBU_PATH | 非零 + 安装提示 | 可读 |
| emit-only | `--emit-only` | 写 .c 成功 | N/A |
