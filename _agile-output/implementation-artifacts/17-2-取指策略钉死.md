### 决议

**选定 (b) — 继续 harness / `instr` 口。**

理由：与 Episode I 一致；17.3 仍单周期改 imm，17.4 插五级时可继续由夹具驱动指令字，避免与 SyncReadMem 读延迟=1、初始化端口纠缠；片上 I-fetch 已有 15.1 SyncReadMem PASS 可后接，不阻塞 hazard 主线。

**(a) 为何本轮不选：** 虽表面可行（AD-21 / 15.1），但会迫使 17.4 同时改 PC→地址、mem read latency 与测试夹具，扩大 blast radius，且非 FR64 教学必证。

### Architecture compliance

- **AD-21：** 延期的片上 IMEM 须用 `SyncReadMem` 友好名；互转仍 `firrtl.mem`。
- **AD-6 / NFR29：** 本故事无新设计依赖。
- **FR69：** 文档唯一策略 + 不得静默混用。
