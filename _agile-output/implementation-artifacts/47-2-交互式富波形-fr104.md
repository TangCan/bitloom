## Intent

**Problem:** Story 47.1 已钉死 NFR14 交互验收（I1–I3 / E1），但产品仍只有静态 `timing.html` + `wave.vcd`（FR38/49）；若仅加强静态表或「请开 GTKWave」会假绿关闭 FR104。

## Dev Notes

### Decision — in-house interactive HTML (I1–I3)

**Select self-contained `interactive.html`** emitted by the existing `wave` CLI (same samples as `timing.html`). Embed lightweight JS for canvas timeline (browse), zoom/pan controls, and signal name search/filter.

Rationale: NFR14 allows I1–I3 **or** E1; in-house avoids third-party WASM/runtime deps in CI; keeps Bitloom brand; static `timing.html` + VCD remain (AD-5/24). GTKWave stays optional supplement, never sole path.

### Architecture

- Viewer lives in **`rhdl-viz`** (toolchain viz). Design crates stay on **`bitloom-prelude` only** (AD-6).
- Reuse `WaveSample` / `samples_from_vcd` already used by FR49 `timing_html`.
- Do **not** remove or weaken `timing.html` / `wave.vcd` emission.
- Signal names in the interactive view must match VCD/`tick` dump names.
