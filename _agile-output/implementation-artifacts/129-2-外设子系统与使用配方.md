# Story 129.2：外设子系统与使用配方

Status: done

## Story

作为实现/集成维护者，我需要交付由真实 AXI-Lite 桥、四窗译码器和 UART/GPIO/Timer/IRQ 四个真实 CSR 外设组成的完整系统，并提供另一种直接 CSR 拓扑及干净 checkout 使用配方，使 FR198 可由实际层级 RTL 验收。

## Acceptance Criteria

1. Given 129.1、127.4、128.2、128.4、128.5 已完成，When 构建本故事，Then 仅使用 bitloom-prelude 的真实定义体，在一次 ElaborateSession 中定义并实例化 bridge、decoder、四个叶；不复制外设算法、不新增 native 层级、不改工具 pin/API 版本。
2. Given 完整 AXI 拓扑，When 运行独立主端，Then AXI AW/W/AR 独立捕获、完整写和读均有响应，四个窗口为 UART 0x0000、GPIO 0x0100、Timer 0x0200、IRQ 0x0300，各 0x100 字节；窗口内空洞/未对齐/访问类型错误为 SLVERR，0x0400–ffff 为 DECERR，高位不别名。
3. Given 完整系统，When 主端配置 Timer、GPIO32、UART 8N1 收发并清 IRQ，Then 真实层级 RTL 观察到寄存器副作用、UART 物理 tx/rx、GPIO pad 和 IRQ 五源行为；IRQ0 Timer、1 RX、2 TX取队首、3 overflow|framing、4 GPIO新沿，清除 sticky pending 后无旧事件重触发，新事件仍可达。
4. Given 第二拓扑，When 直接 CSR 主端运行相同外设向量，Then 它不实例化 AXI 桥且与 AXI 版本具有实质不同的连接图，仍使用同一四窗/四叶定义和事件接线；两图均保存 RTL、TB、命令、工具身份、退出码和 VCD/日志。
5. Given 复位和背压场景，When aresetn 经过公开无状态边界转换为共同同步 reset，Then bridge、decoder、leaf、FIFO、Timer、GPIO、IRQ 同沿清除；AW/W/AR 捕获、待提交、待响应和 FIFO 在 reset 时取消，已发出的物理 UART bit 不承诺回滚；受阻响应保持 payload。
6. Given 干净 checkout，When 执行一条命令，Then 两种拓扑的真实 RTL 验收可复现，不依赖主工作区 target 或 /tmp 隐藏输入；配方记录工具/版本/路径、耗时、手工地址与接线量、源 SHA，缺工具或失败硬失败，不把 emit/旧基座/形式工具发现当系统 PASS。
7. Given 本故事边界，When 完成验证，Then native Interpreter/Compiled/GeneratedFunctional 层级明确 unsupported；direct/FIRRTL/Chisel 结果、有限 formal、原始综合和兼容性分别记录；FR201 核心 CI/贡献模板留给 129.3，Epic130 外部 IP 不在本故事中。
8. Given 七步流程，When ATDD/build/review/automate/regression 全部通过并完成单故事提交，Then 129.2 done、129.3 仍 backlog，FR198 系统交付证据可审计，不宣称 Phase24 或外部试点关闭。
