## Intent

**Problem:** FR136 要求超出 FR128 `GpioSocPad` D1–D4（双 bank×8＝16）的**多外设 / 全芯片 pad 环**产品路径；当前仅有单一 `GpioSocPad`，不得以 FR108 / FR120 C1–C4 / FR128 D1–D4 alone 或 docs-only 关闭本 FR。

**Approach:** 按 NFR14 选定加深子集 **R1–R4**：在 **`bitloom-prelude`**（优先扩展 `ip/gpio/socpad.rs` 或同目录新环类型；**不破坏** FR139 `ip/gpio/{base,vip,socpad}` 路径）交付公开 elaboratable **`ChipPadRing`**（或等价名）：
- **R1** ≥2 外设族 pad 端口：**GPIO SocPad 面**（`pad_out` / `pad_in` / `dir` / masked write）+ **UART pad 侧**（例 `uart_tx` / `uart_wr_*`，对齐 `UartTx` 口形）；
- **R2** 全芯片环形状：≥**3** bank **或** 宽 ≥**24** + 公开 `BANK_COUNT` / `PINS_PER_BANK` / `PAD_WIDTH` / `bank_pin_index`；
- **R3** 环级记分板：期望 vs 观测 pad 序列，覆盖 ≥1 外设副作用（UART 位流 **或** GPIO `pad_out`）；故意错模型 → Fail；
- **R4** ATDD 覆盖 R1–R3；≠ FR128/120/108 alone；≠ docs-only。

最小产品契约页 `docs/fr136-*` 可本故事落地；**Epic 75 关闭勾选 / deferred 收口 → 75.3**。

## Boundaries & Constraints

**Always:** R1–R4；设计 crate → `bitloom-prelude` only；品牌 Bitloom；NFR56 回归 FR98/108/120/128；公开 bank/脚位索引；保留 `GpioSocPad` 行为与 FR139 模块拆分。

**Ask First:** 若强制改选定外设族（非 GPIO+UART）或强制同批 SPI/I2C/AXI pad 复用 / 驱动强度 — 须修订 NFR14。

**Never:** 以 FR108 / FR120 C1–C4 / FR128 D1–D4 alone 关闭 FR136；docs-only；破坏 FR139 `ip/gpio/{base,vip,socpad}` 公开路径；勾选 Epic 75 关闭（→ 75.3）；把 pad 环仿真专用依赖塞进设计 crate；改写 FR98/108/120/128 已关闭为失败。

## I/O & Edge-Case Matrix

| Scenario | Input / State | Expected Output / Behavior | Error Handling |
|----------|--------------|---------------------------|----------------|
| R1 elaborate | `ChipPadRing::elaborate()` | Ok；Verilog 含 GPIO + UART pad 端口 | 缺端口 → ATDD 红 |

## Dev Notes

### Architecture / AD

- AD-6：设计 crate 只依赖 `bitloom-prelude`；环 API 落在 prelude `ip/`。
- FR139：`ip/gpio/{base,vip,socpad}` 拆分保持；新增类型优先挂 `socpad.rs` 或同目录新模块 + re-export。
- NFR14 Epic 75：选定 **GPIO+UART** 多外设 + **≥3 bank 或宽≥24** 全芯片形状；R1–R4。
- NFR56：Phase 12–15 关闭证据（FR98/108/120/128）保留。
- NFR59：SPI/I2C/AXI pad 复用、驱动强度、debounce、模拟差分仍未强制。

### Locked shape (R1–R4) — copy from NFR14

| ID | 钉死 |
| --- | --- |
| **R1** | 环 API ≥2 外设族（GPIO SocPad 面 + UART pad 侧）；elaboratable；prelude only |
| **R2** | 超出双 bank 16：≥3 bank **或** 宽 ≥24 + 公开 bank/脚位索引 |
| **R3** | 环级记分板：期望 vs 观测 pad 序列；≥1 外设副作用；错模型 → Fail |
| **R4** | ATDD 覆盖 R1–R3；≠ FR128/120/108 alone；≠ docs-only |

**推荐钉死形状（减少歧义）：** `BANK_COUNT = 3`，`PINS_PER_BANK = 8`，`PAD_WIDTH = 24`；bank0=`[7:0]`，bank1=`[15:8]`，bank2=`[23:16]`。

### Mirror pattern (FR128)

```text
GpioSocPad (16-bit dual-bank) + fr128_soc_pad D4 scoreboard
  → ChipPadRing (24-bit / 3-bank + uart_tx pad) + fr136 ring scoreboard
```

- 保留 `GpioSocPad` 不变；新类型并行。
- UART 侧可内嵌精简 8N1（`baud_div=0` 路径即可满足位流副作用），端口名建议 `uart_tx` / `uart_wr_en` / `uart_wr_data` / `uart_baud_div` / `uart_tx_busy`（避免与 GPIO `wr_*` 冲突）。
- GPIO 侧：至少 `dir` / `wr_en` / `wr_data` / `wr_mask` / `pad_in` / `pad_out`（宽 24）；IRQ/CSR 非本 FR 强制（仍属 GpioSocPad）。
