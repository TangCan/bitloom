## Intent

**Problem:** `scripts/chisel-fr28-compile.sh` 在缺 Java≥17 / sbt 时 `exit 0` skip，使 FR28「必须编译通过」可被静默冒充。

**Approach:** 新增 **required** 编译路径（独立脚本或原脚本 + require 模式）：缺工具链或 `sbt compile` 失败 → **非零退出**；`build.sbt` 钉死 Chisel 7.14.0 + matching `chisel-plugin`；可选 `BITLOOM_CHISEL_JVM_SKIP=1` 仅逃生舱。不改 GHA / 不强制 `just test`（留给 25.2–25.3）。

## Boundaries & Constraints

**Always:** FR71；NFR12 / AD-9（Chisel 7.14.0 ↔ firtool 1.155.0）；`chisel` + `chisel-plugin` 同版本 + `CrossVersion.full`；至少一黄金 `.scala` 在有工具链时能跑通。

**Ask First:** 绑定非文档化的 Chisel 内部 API。

**Never:** 默认 CI 路径设 SKIP；本故事改 GHA；把 FR28 改回尽力失败；实现 25.2 just / 25.3 GHA。

## I/O & Edge-Case Matrix

| Scenario | Input | Expected |
|----------|-------|----------|
| Required + no Java | required 脚本 / `BITLOOM_REQUIRE_CHISEL_JVM=1` | exit ≠ 0 |
| Required + Java&lt;17 | 同上 | exit ≠ 0 |
| Required + no sbt | 同上 | exit ≠ 0 |
| Required + bad Scala | 语法错误 `.scala` | `sbt compile` 失败 → ≠ 0 |
| SKIP=1 | `BITLOOM_CHISEL_JVM_SKIP=1` | 可 exit 0，须文档声明非默认 CI |
| Optional legacy | 无 require、无 SKIP | 可保留 skip=0（非 CI 合同路径） |

</frozen-after-approval>

## Story

As a 维护者,
I want 缺 Java≥17 / sbt（或等价）或编译失败时脚本非零退出,
So that 无法再以 skip=0 冒充「必须编译通过」。

## Acceptance Criteria

1. 缺 Java≥17、或缺 sbt/coursier、或 `sbt compile` 失败 → **非零退出**（FR71）
2. `build.sbt` 钉死同版本 `chisel` + `chisel-plugin`（`CrossVersion.full`），Chisel **7.14.0**，`scalaVersion` 匹配（NFR12 / AD-9）
3. 若保留 `BITLOOM_CHISEL_JVM_SKIP=1`：文档化，且不得为默认 CI 路径
4. 至少一黄金夹具 `.scala`（或 emit→编译）在有工具链环境下可本地跑通
5. 不改 GHA；不强制改本机 `just test`
