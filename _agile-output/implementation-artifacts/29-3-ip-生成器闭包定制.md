## Intent

**Problem:** IP integrators cannot customize algorithm tables/coefficients with elaborate-time closures on a first-class IP surface; FR77 / Cap-R-63 require overlay on Epic 34 non-stub baselines + Epic 27 Mem init without leaving Fn in backends.

**Approach:** Add `Crc8Lut` IP: default poly `0x07` via `elaborate()`; customize via `elaborate_with_table_fn(violations, Fn(usize)->u64)` on `declare_sync_read_mem_with_init_fn`. SynthesizableClosure violation tokens gate the synthesizable leg (D1). FR82 five-class APIs stay closure-free.

## Boundaries & Constraints

**Always:** FR77 Cap-R-63; NFR36 no closure residue; D1 SynthesizableClosure on synthesizable IP leg; Epic 34 baselines first; Bitloom / `bitloom-prelude` design surface.

**Ask First:** Adding closure params to SyncFifo/UartTx/Spi/I2C/AXI; streaming CRC beyond LUT ROM.

**Never:** Comb/seq synthesizable closures inside IP (Epic 28); HLS HlsFree on synthesizable IP leg; stub wrapped as FR77; store Fn in FrozenHir/emit.

## I/O & Edge-Case Matrix

| Scenario | Expected |
|----------|----------|
| `Crc8Lut::elaborate()` | default poly `0x07` table; emit/tick OK |
| `elaborate_with_table_fn(&[], f)` | custom table in MemDecl.init; tick matches `f` |
| non-empty SynthesizableClosure violations | clear diagnostic (E0143…); no silent default |
| freeze / `.v` / FIRRTL | no closure/`Fn`/`\|\|` IR (NFR36) |
