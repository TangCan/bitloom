## Intent

**Problem:** FR135 要求超出 FR126 `GpioFunctional` 的更多协议手写 FL ≡ tick；当前 UART/SPI/I2C/AXI 仅有 FR103 **GeneratedFunctional**，不得以 Gpio alone / SyncFifo alone / GeneratedFunctional alone 关闭本 FR。

**Approach:** 按 NFR14 选定 MVP **`UartTx`**：在 **`bitloom-sim`** 交付 `UartTxFunctional` + `uart_tx_dual_stimulus` + `IpDualModelMatrix::verify_uart_tx_handwritten`（镜像 FR126 Gpio 体例）；钉死架构端口 `tx` / `tx_byte` / `tx_busy`；Pass + 故意错模型 Fail；ATDD 覆盖 F1–F3。文档产品路径页 `docs/fr135-*` 可在本故事落地最小契约；**Epic 74 关闭勾选 / deferred 收口 → 74.3**。

## Boundaries & Constraints

**Always:** F1–F3；手写 FL 在 `bitloom-sim`；设计 crate → `bitloom-prelude` only；品牌 Bitloom；NFR56 回归 FR103/112/119/126；≠ GeneratedFunctional alone；≠ Gpio/FR126 alone；≠ SyncFifo/FR103 alone。

**Ask First:** 若强制把 MVP 从 `UartTx` 换成其它协议，或要求同批交付全部候选协议 — 须修订 NFR14。

**Never:** 把手写 FL 运行时依赖塞进设计 crate；以 GeneratedFunctional / Gpio / SyncFifo alone 关闭 FR135；勾选 Epic 74 关闭（→ 74.3）；改写 FR103/112/119/126 已关闭为失败。

### Mirror pattern (FR126)

```text
GpioFunctional + gpio_dual_stimulus + verify_gpio_handwritten
  → UartTxFunctional + uart_tx_dual_stimulus + verify_uart_tx_handwritten
```

- 比较架构端口（避免内部 wire）：`tx`, `tx_byte`, `tx_busy`。
- `verify_*` 循环：`set_inputs` → `settle` → `tick` → `fl.cycle` → `compare_named_ports`。
- 故意错模型：`verify_uart_tx_handwritten_with`。

### UartTx behavior (金标准)

- 8N1；`baud_div` = clocks/bit − 1；idle `tx=1`；accept 当 `wr_en && !busy`。
- Sim 对 Reset 输入将 regs 清零（`tick_sequential`）。
- 手写 FL 须匹配 `uart.rs` HIR 下一态与 comb 输出，**不是** GeneratedFunctional。
