# Story 127.4: 静态译码与 M2 关闭

Status: done

## Story

作为实现/集成维护者，我需要可组合的四窗口静态 CSR 译码器，让 AXI-Lite 请求准确到达唯一叶节点，未命中返回可背压的 DECERR，并以真实组合验证关闭 FR196/M2。

估算3–5有效人日；基线 `91828619f66f787c63483dda4b0ee558bb7501e8`。127.1 NFR14 accepted/done、127.2 CSR、127.3桥和M0/M1均done。用户授权全部剩余故事依次create-story→ATDD→build→code-review→automate→实际clean/fmt/regression→单故事commit，取代旧M0-only注记。创建不代表实现或M2关闭；不改已done故事，不推送/发布。FR189/Epic122 deferred及NFR91保持。

## Acceptance Criteria

1. **可组合静态译码。Given** 仅依赖bitloom-prelude的设计，**When** 独立elaborate或在调用者ElaborateSession定义译码器，**Then** 复用同一个无捕获定义体，固定单时钟、同步高有效reset、addr16字节地址/data32/WSTRB4，一个外层finish，无FrozenHir拼接或第二IR。四叶按UART/GPIO/Timer/IRQ顺序对应base `0x0000/0x0100/0x0200/0x0300`、size均`0x100`；完整16位先判断命中，再形成16位local byte offset，保持低两位。公开API/端口/时序在ATDD前固化，逐符号登记FR142/minor，模块复用/实例隔离和连接诊断实测。
2. **地址与错误边界。Given** 任意16位地址，**When** 请求提交，**Then** 四窗选择onehot-or-zero，窗外`0x0400..=0xffff`（包括未对齐）DECERR；窗内hole、未对齐或权限错误由真实CsrBlock给SLVERR，不被decoder升级为DECERR或对齐成合法访问。每窗含末端`xxff`；不截高位形成alias，不新增ID/version寄存器。未命中不向任何叶发req_valid/提交，失败读rdata0，无访问副作用；编码仅00/10/11，01不生成。
3. **唯一提交与锁定响应归属。Given** 合法上游producer及单请求CSR协议，**When** 非reset沿req_valid&&req_ready，**Then** 命中事务上游提交与唯一叶提交同沿，记录owner直到上游响应消费，执行中无第二次提交。req_ready受阻时请求valid和全部payload保持；提交后上游addr/类别可变化，不改变旧响应来源。仅owner可收到rsp_ready，未选叶的ready/valid/data/error变化不能污染上游。DECERR提交也占用唯一在途状态，下一周期才可见响应，背压保持valid/error/data且只消费一次。响应消费沿不接受新请求的保守气泡允许，但必须文档化。
4. **真实M2组合验收。Given** 同一session定义并实例化已交付AxiLiteCsrBridge、新decoder及四个真实CsrBlock，**When** 原始AW/W/AR驱动执行定向和随机黄金序列，**Then** 四窗不同状态、local地址路由、RW/RO/WO/W1C、全部16种WSTRB、零mask、保留位、动态拒绝、读快照与一次副作用正确；AW/W间隔0/1/7/31，部分AW或部分W不饿死合格读。B受阻时可完成有容量的读、R受阻时可完成有容量的写，桥轮转/容量/锁定offer语义保持。组合夹具使用正式寄存器偏移/权限/有效mask；外部状态/event/reject是明确标识的测试peer，不能称Epic128真实UART/GPIO/Timer/IRQ wrapper或Epic129系统交付。层级验收实际运行生成RTL，native/generated层级保持明确unsupported。
5. **共同复位与无重复副作用。Given** 桥、decoder与全部叶同域共同reset，**When** reset与接受/提交/响应竞争或在各在途阶段发生，**Then** reset优先，取消捕获、offer、owner、DECERR/叶待响应及B/R，取消沿不计传输；恢复访问不同窗口时无旧响应重放。覆盖仅AW/仅W/AR、尚未提交、已提交未响应、DECERR受阻、叶响应受阻和B/R受阻。独立记账区分接受、提交、叶副作用、CSR响应、AXI消费与取消；最后排空后继续观察防止迟到重复。同步aresetn断言/释放由外部控制器处理后反相，不能宣称反相即同步器或支持只复位桥。
6. **独立形式、综合及实际证据。Given** 初始reset、合法producer和因果且保持的叶响应，**When** 对原始生成decoder RTL运行实际sby，**Then** 独立断言onehot-or-zero、提交对应、唯一owner、响应路由/保持、未命中无叶提交和reset安全；四窗命中、DECERR、背压恢复及reset后新提交有实际cover。安全不假设上游最终rsp_ready或叶响应等待上界；活性声明另列有限响应/公平性条件。测试observer必须有反例/突变敏感性验证，不能把DUT正确性写成assume。无observer的decoder及真实M2组合RTL执行Yosys综合/check；桥外部5个ready/valid寄存边界保持，以网表依赖锥复验。保存命令/版本/seed/命中/墙钟/退出码及失败，缺工具、UNKNOWN、timeout或ignored不算PASS。
7. **软件产物、文档和兼容。Given** CSR描述同源生成局部Markdown/C头，**When** 文档提供四窗全局base与局部offset组合的可编译prelude-only示例及C消费者，**Then** 独立手写黄金核对完整系统地址及四窗边界，重复生成逐字节一致，多头共同包含无冲突；不改既有local offset宏语义。复用已交付CSR/桥，旧Axi4LiteSlave ADDR8、四寄存器、恒OKAY、同拍AW/W一tick B及read-before-write不变。中文文档说明实际气泡、错误来源、共同reset、支持矩阵与限制，公开名Bitloom且与samitbasu/rhdl无关；不升级工具钉/包版本。

## Dev Notes

### 最小API与周期合同：ATDD前固化

固定四窗ZST `ip::CsrDecoder`，`Elaboratable::elaborate() -> Result<FrozenHir, Diagnostics>` 和 `define_module(&mut ElaborateSession, impl Into<String>) -> Result<String, Diagnostics>`。首版无需任意窗口数、可编程map、多主/ID/burst/可变宽度。固定map在生成器中明确不重叠且端点<=0x10000；不要为了测试非法配置凭空增加公共可配置map。不提供任意map配置接口，因此不虚构该接口的非法map诊断；真实模块名/复用冲突/端口方向和宽度错误仍必须测试。

本次固化上游端口与CsrBlock一致；下游每组严格以`uart_`/`gpio_`/`timer_`/`irq_`前缀。下表为准确接口，ATDD按此生成，不自行改名或改变宽度/方向：

| 接口 | 输入 | 输出 |
|---|---|---|
| 公共 | clk:Clock、rst:Reset | — |
| 上游 | req_valid1、write1、addr16、wdata32、wstrb4、rsp_ready1 | req_ready1、rsp_valid1、rdata32、error2 |
| 每个下游P | P_req_ready1、P_rsp_valid1、P_rdata32、P_error2 | P_req_valid1、P_write1、P_addr16、P_wdata32、P_wstrb4、P_rsp_ready1 |

桥`csr_*`连decoder上游去前缀的同名端口；decoder下游连leaf去窗口前缀的同名端口。全部模块先define，再声明顶层和instances，最后finish一次。CSR leaf本来就比较完整16位local offset，C header本来也是local；例如0x0104命中GPIO后传0x0004，0x8104不得先截成0x0004。窗内0x01ff传0x00ff得到SLVERR；窗外0xffff直接DECERR。write/wdata/wstrb保持，不用截断或零WSTRB优化跳过请求。

固定不增加请求缓存：空闲时向唯一命中叶透传请求，upstream ready仅取该叶ready；错失可接受并在沿后置本地DECERR pending。命中提交沿锁定owner，leaf下一周期已有锁存响应；从owner路由rsp_valid/data/error且仅owner接收rsp_ready。这样沿前leaf commit与桥CSR commit相同，保持原提交点；不能先接受到decoder、后续另拍才执行leaf却称同一提交。执行中不允许新req，响应消费沿保持气泡。背压保持义务只跨无reset周期成立，reset沿清除observer历史并取消事务，不要求旧响应继续保持。rsp受阻稳定可依赖合法leaf稳定协议，无需另造重复叶存储；上游输入变化不影响owner。未选leaf的无关输入不能接管response；formal明确因果响应假设与非法peer非产品输入边界。

reset时上游req_ready、所有downstream req_valid/rsp_ready均为0；上游rsp_valid不组合门控rst，按pending/owner及合法叶寄存响应路由，在有效reset沿后清零，与现有leaf一致。reset沿前可能仍有rsp_valid，不计作消费。内部CSR组合路径允许；桥外部AWREADY/WREADY/ARREADY/BVALID/RVALID仍只依赖寄存状态，不能因新增decoder破坏。

DECERR无叶owner而有独立本地响应状态，下一周期响应，rdata0；不能将组合`!hit`直接当rsp_valid，否则改变addr会破坏背压。合法叶不会生成01，decoder不得凭空发明保留码修复/超时机制；不要求失败写的无关rdata为0，失败读才有零数据约束。

### M2夹具的正式寄存器布局

以下均为各窗local byte offset，reset0；四窗base另加。采用已交付CsrBlock定义真实RTL，外部owner/事件/拒绝由测试peer提供，不实现外设算法。

| 窗口 | offset / register / access / valid mask |
|---|---|
| UART 0000 | 00 CTRL RW 1；04 BAUD_DIV RW ffffffff；08 STATUS RO f；0c TX_DATA WO ff；10 RX_DATA RO ff；14 EVENT W1C f |
| GPIO 0100 | 00 DIR RW ffffffff；04 OUT RW ffffffff；08 IN RO ffffffff；0c SET WO ffffffff；10 CLEAR WO ffffffff；14 RISE_EVENT W1C ffffffff |
| Timer 0200 | 00 CTRL RW 3；04 COUNT RW ffffffff；08 COMPARE RW ffffffff；0c EVENT W1C 1 |
| IRQ 0300 | 00 PENDING W1C 1f；04 ENABLE RW 1f；08 TEST WO 1f；0c RAW RO 1f |

不把GPIO32/IRQ5降为历史GPIO8/IRQ8。动态寄存器单owner：RW External/RO External读peer当前值，WO None产生commit，W1C Leaf保存并按set优先更新；沿前commit只能在成功访问产生，有效mask0不产生write pulse。窗口名不等于真实UART串行、Timer计数/IRQ汇聚或GPIO同步逻辑已实现。测试可对peer执行外部状态/事件/拒绝变化与副作用计数，明确其验证的是连接和CSR语义。
