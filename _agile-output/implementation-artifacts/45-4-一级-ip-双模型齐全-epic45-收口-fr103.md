## Dev Notes

### Decision — SyncFifo handwritten FL

`GeneratedFunctional` 对 `MemRead` 返回 0（见 `bitloom-sim/src/generate.rs`）；SyncFifo 含 `declare_mem`。探测：仅 `rst` 字母表时 random FormalEquiv 可绿（空操作），但对 `rst/wr_en/rd_en` 会 Fail。**FR103 合同：** SyncFifo 功能模型 = **手写** `AbstractionView`（队列语义 ↔ PortValues），周期模型 = `Sim::tick`；文档须写明「生成 FL alone ≠ SyncFifo 双模型完成」。UART/SPI/I2C/AXI（无 Mem）可用 `GeneratedFunctional` + `FormalEquivProduct` / 钉死刺激。

### Architecture

- AD-5 / AD-17：双模型对照仅 `PortValues`；周期只从 FrozenHir `tick`。
- AD-6：设计 crate 只依赖 `bitloom-prelude`；联验 API 在 `bitloom-sim`（工具链）。
- FR100 产品入口已在；本故事是 **IP 级联验矩阵** + Epic 收口，不是重做 FormalEquivProduct。
- FR92/FR78 adapter = **配套非充分**（NFR14）；不得单独关 FR103。
- SystemC TLM-2.0 = **Epic 46 / FR101**；关闭 Epic 45 **不**关闭 TLM 产品。
